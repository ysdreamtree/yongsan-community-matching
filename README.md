# 용산구시설관리공단 지역상생 협력 매칭 플랫폼

이 묶음은 실제 서버·데이터 저장 구조를 개발하기 시작한 소스입니다. 지금은 공단의 실제 접수 창구가 아닙니다. 운영 환경·개인정보 처리 기준·직원 계정 관리가 확정되기 전에는 실제 연락처 등 개인정보를 입력하거나 외부 공개를 시작하지 마세요.

## 이번에 구현한 기능

- 참여자 ID·무작위 인증키 발급 및 로그인, SQLite 데이터 저장
- 협력 제안·관심 등록·추천, 내 신청 조회·수정·공개 요청 철회
- 공개 요청 및 총괄 승인 후 공개 게시, 수정 시 재승인
- 승인된 직원의 제안별 연결 의사 등록·철회, 중복 제외 공개 집계
- 총괄의 공개 승인, 직원 활성화·중지, 담당자 배정, 진행 상태·안내·내부 기록
- 배정 직원의 비공개 상세·회신 창구 확인 및 협의 기록
- 총괄용 월별 공개 승인 목록 CSV 내려받기(연락처·직원 메시지 제외)
- 로그인 실패 제한, 서버 측 역할·배정 확인, 요청 출처·CSRF 확인, 인증키 원문 미저장

## 개발용 로컬 실행

Python 3.10 이상(표준 라이브러리만 사용)이 필요합니다. 터미널에서 이 폴더로 이동한 뒤 실행합니다.

```sh
python server.py
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 이것은 실행한 컴퓨터 내부에서만 열리는 개발 서버입니다. 종료하려면 Ctrl+C를 누릅니다. 기본 설정에서는 신규 계정 발급이 닫혀 있습니다. 데이터 파일은 `data/platform.sqlite3`에 생기며 인증키 원문은 저장되지 않습니다.

총괄 또는 직원 계정은 시스템 관리자만 해당 컴퓨터의 터미널에서 발급합니다. 인증키는 화면에 표시되지 않는 입력란에 설정하며, 발급된 ID는 담당자가 안전한 경로로 보관해야 합니다.

```sh
python server.py provision admin 총괄담당자
python server.py provision staff 사업담당자
```

이 계정 발급 절차는 개발·구축용입니다. 실제 직원 신원 검증, 공단 계정 연동, 다중 인증 및 계정 회수는 배포 환경에 맞게 마련해야 합니다.

## 개인정보 안내 및 접수 잠금

신규 계정 발급은 기본적으로 잠겨 있습니다. 별도 운영 기준이 확정되기 전까지 잠금 상태를 유지하세요. 개발용 가상 데이터를 사용한 기능 점검에는 개인정보 안내 문구 파일과 버전을 환경변수로 지정해야 합니다.

```sh
MATCH_REGISTRATION_ENABLED=1 MATCH_PRIVACY_NOTICE_FILE=/절대경로/안내문.txt MATCH_PRIVACY_VERSION=버전 python server.py
```

이는 기술적인 개방 조건일 뿐 개인정보 처리의 적법성이나 공단 내부 승인을 의미하지 않습니다. 실제 공개 전에는 수집·이용 목적과 항목, 보유기간, 외부 제공 여부, 권리·처리 절차를 확정하고 안내해야 합니다. 안내 내용은 그대로 웹화면에 표시되며 확인과 안내 버전을 기록합니다.

## 실행 검증

```sh
python tests/test_service.py
```

가상 데이터와 임시 데이터베이스를 사용합니다. 서버 재시작 후 계정 유지, 신청자 간 접근 제한, 공개 승인·재승인, 직원 중복 집계·담당자 배정, 비공개 정보 보호, 요청 출처 및 CSRF 검사를 확인합니다.

## 실제 공개 전 추가로 필요한 사항

- 공단이 허용하는 호스팅·저장 위치, 운영 주체, 개인정보 처리·보유·삭제 및 백업·복구 정책 결정
- 운영용 웹서버와 HTTPS, 도메인, 접근 제어, 로그·모니터링, 보안 점검 및 부하·취약점 시험. 제공된 Python 개발 서버는 로컬에만 바인딩되며 인터넷에 직접 공개하도록 만들어지지 않았습니다.
- 승인된 공단 직원 본인 확인, MFA 또는 공단 직원 인증 연계, 총괄 지정 및 권한 변경 절차
- 인증키 분실 시 본인 확인과 재발급, 비밀번호 변경, 계정 삭제·개인정보 처리 요청 절차
- 스팸·대량 접수 대응, 알림 발송 연동, 관리자 수동 복구 및 실운영 절차
- 독서경영·예술로의 실제 참여 대상, 사업 범위, 일정 및 예산 검증 후 표시
- 실제 데이터와 사용자 환경에서 기능·접근성·모바일 및 크로스브라우저 검증

현재 자동 알림 발송, 직원 온라인 가입 심사, 계정 복구·삭제 및 관리형 백업은 구현되지 않았습니다. 운영 승인과 점검이 끝나기 전에는 공단 홈페이지 연결이나 대외 QR 홍보를 진행하지 마세요.
